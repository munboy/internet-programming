## 1 ПОСТАНОВКА ЗАВДАННЯ

У методичних вказівках розібрано приклад таблиці книг: записи створюються функцією-конструктором і зберігаються в масиві, таблиця будується методами createElement, createTextNode і appendChild, а клік по заголовку стовпця сортує записи функцією quickSort. Повторний клік по тому ж стовпцю не сортує масив заново, а виводить його у зворотному порядку (функція allocator).

У лекції 3 розглянуто змінні let і const, функції та стрілкові функції, пошук елементів (getElementById, querySelector), створення й видалення вузлів, різницю між textContent та innerHTML (ризик XSS), керування класами через classList, події, делегування подій і preventDefault.

Завдання роботи: додати до сайту «Coffee Shop» з лабораторної роботи №2 клієнтську логіку на чистому JavaScript без сторонніх бібліотек.

### 2.1 Підключення скриптів

Для кожної сторінки написано окремий файл (таблиця 2.1). Скрипт підключено в <head> з атрибутом defer: браузер завантажує файл паралельно з розбором HTML, а виконує його тільки після того, як DOM побудовано. ### 2.2 Головна сторінка: годинник і акція

Функція updateClock створює об'єкт Date, форматує дату і час методами toLocaleDateString та toLocaleTimeString для локалі uk-UA і записує результат у тег <time>. Функція викликається одразу і далі щосекунди через setInterval. Заодно вона перевіряє годину: з 18:00 картці акції «Друга чашка -50%» додається клас promo-active, і картка підсвічується.

**Лістинг 2.2 - Файл main.js**

```javascript
// main.js - головна сторінка: годинник у шапці та стан вечірньої акції.
// Скрипт підключено з атрибутом defer, тому DOM уже побудований.

const clock = document.getElementById('clock');
const promoCard = document.getElementById('evening-promo');
const promoState = document.getElementById('promo-state');

const PROMO_START_HOUR = 18; // "друга чашка -50%" діє з 18:00

function updateClock() {
    const now = new Date();

    const date = now.toLocaleDateString('uk-UA', {
        weekday: 'long',
        day: 'numeric',
        month: 'long',
        year: 'numeric'
    });
    const time = now.toLocaleTimeString('uk-UA');

    clock.textContent = date + ', ' + time;
    clock.setAttribute('datetime', now.toISOString());

    // вмикаємо або вимикаємо підсвічування акції
    if (now.getHours() >= PROMO_START_HOUR) {
        promoCard.classList.add('promo-active');
        promoState.textContent = 'Акція діє зараз!';
    } else {
        promoCard.classList.remove('promo-active');
        const hoursLeft = PROMO_START_HOUR - now.getHours();
        promoState.textContent = 'Почнеться о 18:00 (приблизно через ' + hoursLeft + ' год.)';
    }
}

updateClock();
setInterval(updateClock, 1000);
```

function renderItems() {
    itemsBody.innerHTML = ''; // очищаємо старі рядки

    if (orderItems.length === 0) {
        const tr = document.createElement('tr');
        tr.className = 'empty-row';
        const td = createCell('Чек порожній. Додайте напій зі списку вище.');
        td.colSpan = 5;
        tr.appendChild(td);
        itemsBody.appendChild(tr);
    }

    orderItems.forEach(function (item, index) {
        const tr = document.createElement('tr');
        tr.appendChild(createCell(item.name));
        tr.appendChild(createCell(item.qty, 'center'));
        tr.appendChild(createCell(formatMoney(item.price), 'num'));
        tr.appendChild(createCell(formatMoney(item.price * item.qty), 'num'));

        // кнопка видалення знає індекс свого рядка в масиві
        const tdButton = document.createElement('td');
        tdButton.className = 'center';
        const button = document.createElement('button');
        button.type = 'button';
        button.className = 'btn-remove';
        button.textContent = 'Видалити';
        button.dataset.index = index;
        tdButton.appendChild(button);
        tr.appendChild(tdButton);

        itemsBody.appendChild(tr);
    });

### 2.4 Клієнти: пошук і реєстрація

Пошук працює на подію input, тобто після кожного введеного символу. Функція renderCustomers відбирає методом filter клієнтів, у яких ім'я, телефон або пошта містять рядок запиту, і показує лічильник «Показано N з M». Знайдений фрагмент підсвічується тегом <mark>: текст комірки ділиться на три частини, крайні вставляються як текстові вузли createTextNode, середня обгортається в <mark>. Через innerHTML це зробити простіше, але тоді введений у пошук HTML-код виконався б.

**Лістинг 2.8 - Підсвічування знайденого фрагмента (customers.js)**

```javascript
// комірка, у якій знайдений фрагмент обгорнуто тегом <mark>.
// Текст вставляється через createTextNode, тому HTML з поля пошуку не виконується
function createHighlightedCell(text, query) {
    const td = document.createElement('td');
    const position = text.toLowerCase().indexOf(query);

    if (query === '' || position === -1) {
        td.textContent = text;
        return td;
    }

    const mark = document.createElement('mark');
    mark.textContent = text.substring(position, position + query.length);

    td.appendChild(document.createTextNode(text.substring(0, position)));
    td.appendChild(mark);
    td.appendChild(document.createTextNode(text.substring(position + query.length)));
    return td;
}
```

**Лістинг 2.9 - Перевірка та форматування телефону (customers.js)**

```javascript
// +380501234567, 0501234567, +38 (050) 123-45-67 -> "+380 (50) 123-45-67"
function normalizePhone(value) {
    let digits = value.replace(/\D/g, ''); // залишаємо тільки цифри
    if (digits.length === 10 && digits[0] === '0') {
        digits = '38' + digits;
    }
    if (!/^380\d{9}$/.test(digits)) {
        return null;
    }
    return '+380 (' + digits.substring(3, 5) + ') ' + digits.substring(5, 8) + '-' +
        digits.substring(8, 10) + '-' + digits.substring(10);
}
```

Поле з помилкою отримує клас invalid (червона рамка), а під формою з'являється пояснення. Після успішної реєстрації клієнт отримує наступний вільний ID, а якщо стоїть позначка, то й картку з 10 стартовими бонусами в таблиці карток.

### 2.5 Персонал: сортування за прикладом з методички

Сторінку персоналу зроблено за схемою прикладу з методички. Запис про працівника створює функція-конструктор Barista, записи зберігаються в масиві, а таблиця будується функцією renderTable. Відповідність частин прикладу і проєкту наведено в таблиці 2.2.

**Таблиця 2.2 - Порівняння з прикладом з методички**

| Методичка (таблиця книг) | Проєкт (таблиця бариста) |
| --- | --- |
| конструктор fillArray(years, books, authors) | конструктор Barista(id, name, phone, shop, shift, status) |
| масив txt | масив baristas |
| quickSort(l, h, type) з порівнянням isLow і вагами символів weight | quickSort(list, field) з функцією compare і localeCompare('uk') |
| allocator(arg): повторний клік виводить масив у зворотному порядку | sortBy(field): повторний клік викликає reverse() |
| createTable: createElement, createTextNode, appendChild | renderTable: createElement, textContent, appendChild |
| посилання javascript:allocator(...) у шапці | атрибут data-field у <th> і один обробник click на <thead> |

У методичці для правильного порядку кириличних літер написано окрему функцію weight, яка змінює коди символів. У проєкті цю задачу виконує метод localeCompare з локаллю uk: він знає порядок українського алфавіту, зокрема літер і, ї, є, ґ. **Лістинг 2.11 - Швидке сортування і обробка повторного кліку (baristas.js)**

```javascript
// порівняння двох записів за полем: числа віднімаємо,
// рядки порівнюємо з урахуванням українського алфавіту
function compare(a, b, field) {
    if (typeof a[field] === 'number') {
        return a[field] - b[field];
    }
    return a[field].localeCompare(b[field], 'uk');
}

// швидке сортування: опорний елемент посередині, менші ліворуч, більші праворуч
function quickSort(list, field) {
    if (list.length <= 1) {
        return list;
    }

    const pivot = list[Math.floor(list.length / 2)];
    const less = [];
    const equal = [];
    const greater = [];

    list.forEach(function (item) {
        const result = compare(item, pivot, field);
        if (result < 0) {
            less.push(item);
        } else if (result > 0) {
            greater.push(item);
        } else {
            equal.push(item);
        }
    });

    return quickSort(less, field).concat(equal, quickSort(greater, field));
}

// як allocator() у методичці: повторний клік по тому ж стовпцю
// не сортує заново, а лише перевертає масив
function sortBy(field) {
    if (field === sortField) {
        baristas.reverse();
        sortAsc = !sortAsc;
    } else {
        baristas = quickSort(baristas, field);
        sortField = field;
        sortAsc = true;
    }
    updateHeaderArrows();
    renderTable();
}
```

Стрілка біля активного заголовка (▲ або ▼) малюється псевдоелементом ::after із CSS, а скрипт лише перемикає класи sort-asc і sort-desc. Обробник кліку висить на всій шапці таблиці: метод closest('th') знаходить заголовок, на якому клікнули, а dataset.field повідомляє, за яким полем сортувати. Фільтр за філіалом працює на подію change і застосовується разом із сортуванням.

### 2.7 Аналітика

Усі три звіти залишилися в HTML, а скрипт показує лише вибраний. Метод classList.toggle з другим аргументом додає клас hidden усім звітам, крім вибраного. Кількість рядків у рядку стану не записана вручну, а рахується через querySelectorAll('tbody tr'). Звіт перемикається і при зміні списку (подія change), і кнопкою «Сформувати».

**Лістинг 2.13 - Файл analytics.js**

```javascript
// analytics.js - перемикання аналітичних звітів без перезавантаження сторінки.
// Показується лише вибраний звіт, інші ховаються класом .hidden.

const reportSelect = document.getElementById('query-select');
const runButton = document.getElementById('btn-run-query');
const statusLine = document.getElementById('report-status');
const reports = document.querySelectorAll('.report');

function showReport() {
    const selected = 'section-' + reportSelect.value; // наприклад, section-rank
    let rowsCount = 0;

    reports.forEach(function (section) {
        const isSelected = section.id === selected;
        // toggle з другим аргументом: true - додати клас, false - прибрати
        section.classList.toggle('hidden', !isSelected);
        if (isSelected) {
            rowsCount = section.querySelectorAll('tbody tr').length;
        }
    });

    // назва звіту без номера на початку ("2. Рейтинг..." -> "Рейтинг...")
    const title = reportSelect.options[reportSelect.selectedIndex].text.replace(/^\d+\.\s*/, '');
    const time = new Date().toLocaleTimeString('uk-UA');
    statusLine.textContent = 'Сформовано звіт «' + title + '». Рядків: ' + rowsCount + '. Час: ' + time + '.';
}

reportSelect.addEventListener('change', showReport);
runButton.addEventListener('click', showReport);

showReport();
```

## ВИСНОВКИ

У лабораторній роботі сайт «Coffee Shop» отримав клієнтську логіку на JavaScript без сторонніх бібліотек. Дані чека, історії продажів, клієнтів, карток і персоналу зберігаються в масивах об'єктів, а таблиці будуються з них через DOM. Сторінку персоналу зроблено за прикладом з методички: конструктор записів, швидке сортування за кліком на заголовку і зворотний порядок при повторному кліку, при цьому порівняння рядків виконує localeCompare з українською локаллю.

На практиці застосовано обробку подій click, input, change, submit і reset, делегування подій, керування класами через classList, перевірку форм регулярними виразами та нарахування бонусів за правилами курсового застосунку. Увесь текст від користувача виводиться через textContent, тому введений HTML-код не виконується.
