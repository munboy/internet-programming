## 1 ПОСТАНОВКА ЗАВДАННЯ

Згідно з методичними вказівками потрібно створити HTML-документ, у якому використано текстові блоки й заголовки, форматування тексту, списки, гіперпосилання, зображення та таблиці. На консультації до лабораторної роботи викладач уточнив вимоги:

- сайт має складатися щонайменше з трьох-чотирьох сторінок, пов'язаних гіперпосиланнями;
- у таблицях потрібно об'єднати комірки по горизонталі та по вертикалі, наприклад зробити дворівневу шапку;
- на зображення потрібно накласти карту (<map>, <area>) з областями різної форми, де кожна область має власну спливаючу підказку та власне посилання;
- фрейми можна додати за бажанням.
Усі лабораторні роботи курсу виконуються в межах однієї предметної області: кожна наступна робота додає до вже створеного сайту новий шар (стилі, поведінку, роботу із сервером).

## 3 ХІД ВИКОНАННЯ РОБОТИ

### 3.1 Структура сторінок і навігація

Усі п'ять сторінок мають однакову будову: шапка <header> з логотипом і назвою, меню <nav>, основний вміст <main>, поділений на розділи <section>, і підвал <footer>. Пункт меню поточної сторінки виділено тегом <b>. Пункти розділено символом «|» і горизонтальними лініями <hr>.

Логотип на головній сторінці розміщено всередині тега <a>, тому клік по ньому відкриває зображення в повному розмірі в новій вкладці (атрибут target="_blank"). Атрибут border="0" прибирає рамку, яку браузер малює навколо зображення-посилання. У тексті є зовнішнє посилання на статтю Вікіпедії, а в підвалі посилання mailto: для листа на пошту мережі.

**Лістинг 3.1 - Шапка та меню головної сторінки (index.html)**

```html
<header>
    <div align="center">
        <!-- логотип відкриває зображення у повному розмірі -->
        <a href="img/coffee_logo.png" target="_blank" title="Відкрити логотип у повному розмірі">
            <img src="img/coffee_logo.png" alt="Логотип Coffee Shop" width="100" height="100" border="0">
        </a>
        <h1>Мережа кав'ярень «Coffee Shop»</h1>
        <p><i>Свіжообсмажена кава, затишна атмосфера та привітні бариста у кожному філіалі</i></p>
    </div>
    <hr>
    <nav align="center">
        <b><a href="index.html">Головна</a></b> |
        <a href="orders.html">Оформлення замовлень</a> |
        <a href="customers.html">Клієнти та картки</a> |
        <a href="baristas.html">Співробітники</a> |
        <a href="analytics.html">Аналітика</a>
    </nav>
    <hr>
</header>
```

### 3.2 Текст і форматування

На сторінках використано всі шість рівнів заголовків: <h1> для назви сторінки, <h2> для розділів, <h3> для підрозділів, <h4> для заголовків новин і блоку «Контакти», <h5> у підвалі, а <h6> з атрибутом align="right" для підпису під цитатою, як у прикладі з методички. Абзаци задано тегом <p>, перенесення рядка в новинах тегом <br>, цитату шеф-бариста тегом <blockquote>.

Теги форматування застосовано за змістом, а не окремим демонстраційним блоком. У розділі «Пропозиції тижня» назва акційного напою виділена тегами <big> і <b>, стара ціна закреслена тегом <s>, нова ціна виділена кольором через <font color>, термін дії акції набрано тегом <small>, умова вечірньої акції виділена курсивом <i> і підкресленням <u>. Верхній індекс <sup> використано для степеня в кількості чашок за рік, для квадратних метрів площі залу та для позначки градусів, нижній індекс <sub> у формулі кофеїну C8H10N4O2.

**Лістинг 3.2 - Розділ «Пропозиції тижня» (index.html)**

```html
<h2>Пропозиції тижня</h2>
<p>
    <big><b>Лавандовий раф</b></big> за спеціальною ціною:
    <s>80 грн</s> <font color="#B22222"><b>70 грн</b></font>
    <small>(пропозиція діє до 31.10.2026)</small>
</p>
<p>
    <i>Друга чашка зі знижкою 50%</i> щодня <u>після 18:00</u> у всіх філіалах.
</p>
<p>
    Сніданок до 11:00: <b>круасан + американо</b> за <font color="#B22222"><b>75 грн</b></font>
    замість 85 грн.
</p>
<p>
    <small>Цікаво: молекула кофеїну має формулу C<sub>8</sub>H<sub>10</sub>N<sub>4</sub>O<sub>2</sub>,
    а для екстракції еспресо ми використовуємо воду температурою 92-94 <sup>o</sup>C.</small>
</p>
```

### 3.3 Списки

На головній сторінці використано такі види списків:

- маркерований список <ul type="square"> з квадратними маркерами (сорти кавового зерна);
- маркерований список <ul type="circle"> з маркерами-колами (послуги для гостей);
- нумерований список <ol> (етапи приготування капучино), у четвертий пункт якого вкладено ще один список <ol type="a"> з літерною нумерацією;
- нумерований список <ol type="I"> з римськими цифрами (розділи меню);
- список визначень <dl>, <dt>, <dd> (словник бариста).
На сторінці клієнтів правила бонусної програми поділено на дві частини. Між ними стоїть абзац, тому другий список має атрибут start="4", щоб нумерація продовжилася з четвертого пункту.

**Лістинг 3.3 - Нумерований список із вкладеним списком (index.html)**

```html
<h3>Як ми готуємо капучино</h3>
<ol>
    <li>Мелемо 18 г зерна безпосередньо перед приготуванням.</li>
    <li>Темперуємо каву із зусиллям близько 15 кг.</li>
    <li>Екстрагуємо еспресо 25-28 секунд під тиском 9 бар.</li>
    <li>Готуємо молоко:
        <ol type="a">
            <li>наливаємо холодне молоко в пітчер;</li>
            <li>збиваємо парою до 60-65 <sup>o</sup>C;</li>
            <li>вливаємо в еспресо, малюючи візерунок.</li>
        </ol>
    </li>
    <li>Подаємо гостю разом зі склянкою води.</li>
</ol>
```

**Лістинг 3.4 - Продовження нумерації атрибутом start (customers.html)**

```html
<h2>Правила програми лояльності</h2>
<ol>
    <li>Картку видаємо безкоштовно під час реєстрації клієнта.</li>
    <li>З кожного замовлення на картку повертається <b>10%</b> суми у вигляді бонусів.</li>

<p><i>Додаткові умови:</i></p>
<ol start="4">
    <li>Бонусами можна оплатити не більше половини чека.</li>
    <li>Бонуси, якими не користувалися 12 місяців, згорають.</li>
</ol>
```

### 3.4 Таблиці

**Таблиця філіалів має дворівневу шапку. Стовпці «№» і «Філіал» об'єднано по вертикалі атрибутом rowspan="2", а заголовки «Контакти» і «Графік роботи» об'єднують по два стовпці атрибутом colspan="2". У тілі таблиці також є вертикальне об'єднання: філіали 2 і 3 у вихідні працюють однаково, тому ця комірка має rowspan="2", а в рядку третього філіалу її немає. Над таблицею розміщено підпис <caption>, шапку і тіло розділено тегами <thead> і <tbody>.**

Вигляд таблиць задано атрибутами з методички: border (товщина рамки), cellpadding (відступ від рамки до вмісту), cellspacing (відстань між комірками), width (ширина), bgcolor (колір фону рядка) та align (вирівнювання в комірці).

**Лістинг 3.5 - Таблиця філіалів з об'єднанням комірок (index.html)**

```html
<table border="1" cellpadding="8" cellspacing="0" width="100%">
```

### 3.5 Зображення та карта зображення

Для карти мережі підготовлено зображення coffee_map.png розміром 600 на 200 пікселів, на якому схематично показано три філіали різної форми. Тегу <img> задано атрибут usemap="#shops-map", який зв'язує зображення з картою <map name="shops-map">. Усередині карти чотири області <area>:

- shape="rect": прямокутник, координати лівого верхнього та правого нижнього кутів (10,10,190,190);
- shape="circle": коло, координати центру та радіус (300,100,75);
- shape="poly": замкнута ламана, координати чотирьох вершин трапеції;
- shape="default": уся решта зображення, що не увійшла в інші області.
Кожна область має власну підказку title з адресою філіалу та власне посилання href. Області філіалів відкривають їхню адресу на Google Maps у новій вкладці, а область default переходить до таблиці філіалів на цій самій сторінці (посилання #branches на id розділу).

**Лістинг 3.6 - Зображення з картою активних областей (index.html)**

```html
<img src="img/coffee_map.png" alt="Схема розташування філіалів" usemap="#shops-map" width="600" height="200" border="1">
<map name="shops-map">
```

### 3.6 Фрейм і форми

Внизу головної сторінки за допомогою плаваючого фрейму <iframe> вбудовано сторінку замовлень. Так касовий модуль можна відкрити, не залишаючи головну сторінку. Між тегами фрейму записано текст із посиланням, який побачить користувач браузера без підтримки фреймів.

Головну сторінку зібрано з блоків так само, як у прикладі з методички. Загальний контейнер .container має максимальну ширину 1100 px і вирівнюється по центру за рахунок margin: 0 auto. **Лістинг 2.4 - Каркас головної сторінки (вміст блоків пропущено)**

### 2.5 Блокова модель

Кожен елемент браузер розглядає як прямокутник з чотирьох шарів: вміст (content), внутрішній відступ (padding), рамка (border) і зовнішній відступ (margin). Для всіх елементів задано box-sizing: border-box, тому значення width включає padding і border. Наприклад, блок новини .news-item має padding: 14px 16px, рамку 1 px і margin-bottom: 12px. Внутрішня ширина контейнера дорівнює 1100 - 2 * 32 - 2 * 1 = 1034 px, бічна колонка займає 31% від неї, тобто приблизно 320 px. Оскільки padding і рамка входять у цю ширину, на текст новини залишається 320 - 2 * 16 - 2 * 1 = 286 px, і колонка не виходить за межі макета.

**Лістинг 2.9 - Модель border-box (style.css)**

```css
/* ширина блоку враховує padding і border */
* {
    box-sizing: border-box;
}
```

### 2.6 Селектори, каскад і специфічність

У файлі стилів використано різні види селекторів (таблиця 2.3).

**Таблиця 2.3 - Види селекторів у style.css**

| Вид селектора | Приклад | Призначення |
| --- | --- | --- |
| тег | body, h2, fieldset | базовий шрифт, фон, заголовки |
| клас | .container, .btn, .news-item | більшість правил проєкту |
| ідентифікатор | #lbl-total | велика сума до сплати в чеку |
| нащадок | .main-nav a, .offer-card h3 | посилання меню, заголовок картки |

| сусідній елемент | .data-table thead tr + tr th | другий рядок дворівневої шапки |
| атрибут | input[type="text"], th[colspan] | поля форм, заголовок над кількома стовпцями |
| псевдоклас | :hover, :focus, :nth-child(even), :root | наведення, фокус, «зебра», змінні |
| псевдоелемент | blockquote::before | велика лапка перед цитатою |

Під час оформлення таблиць звітів виникла ситуація, яка добре показує роботу каскаду. Правило «зебри» .data-table tbody tr:nth-child(even) має специфічність (0,2,2): клас, псевдоклас і два теги. ### 2.2 Головна сторінка: годинник і акція

Функція updateClock створює об'єкт Date, форматує дату і час методами toLocaleDateString та toLocaleTimeString для локалі uk-UA і записує результат у тег <time>. Функція викликається одразу і далі щосекунди через setInterval. Заодно вона перевіряє годину: з 18:00 картці акції «Друга чашка -50%» додається клас promo-active, і картка підсвічується.

**Лістинг 2.2 - Файл main.js**

```javascript
// main.js - головна сторінка: годинник у шапці та стан вечірньої акції.
// Скрипт підключено з атрибутом defer, тому DOM уже побудований.

const clock = document.getElementById('clock');
const promoCard = document.getElementById('evening-promo');
const promoState = document.getElementById('promo-state');

const PROMO_START_HOUR = 18; // "друга чашка -50%" діє з 18:00

function updateClock() {
    const now = new Date();

    const date = now.toLocaleDateString('uk-UA', {
        weekday: 'long',
        day: 'numeric',
        month: 'long',
        year: 'numeric'
    });
    const time = now.toLocaleTimeString('uk-UA');

    clock.textContent = date + ', ' + time;
    clock.setAttribute('datetime', now.toISOString());

    // вмикаємо або вимикаємо підсвічування акції
    if (now.getHours() >= PROMO_START_HOUR) {
        promoCard.classList.add('promo-active');
        promoState.textContent = 'Акція діє зараз!';
    } else {
        promoCard.classList.remove('promo-active');
        const hoursLeft = PROMO_START_HOUR - now.getHours();
        promoState.textContent = 'Почнеться о 18:00 (приблизно через ' + hoursLeft + ' год.)';
    }
}

updateClock();
setInterval(updateClock, 1000);
```

```javascript
function createHighlightedCell(text, query) {
    const td = document.createElement('td');
    const position = text.toLowerCase().indexOf(query);

    if (query === '' || position === -1) {
        td.textContent = text;
        return td;
    }

    const mark = document.createElement('mark');
    mark.textContent = text.substring(position, position + query.length);

    td.appendChild(document.createTextNode(text.substring(0, position)));
    td.appendChild(mark);
    td.appendChild(document.createTextNode(text.substring(position + query.length)));
    return td;
}
```

```javascript
// порівняння двох записів за полем: числа віднімаємо,
// рядки порівнюємо з урахуванням українського алфавіту
function compare(a, b, field) {
    if (typeof a[field] === 'number') {
        return a[field] - b[field];
    }
    return a[field].localeCompare(b[field], 'uk');
}

// швидке сортування: опорний елемент посередині, менші ліворуч, більші праворуч
function quickSort(list, field) {
    if (list.length <= 1) {
        return list;
    }

    const pivot = list[Math.floor(list.length / 2)];
    const less = [];
    const equal = [];
    const greater = [];

    list.forEach(function (item) {
        const result = compare(item, pivot, field);
        if (result < 0) {
            less.push(item);
        } else if (result > 0) {
            greater.push(item);
        } else {
            equal.push(item);
        }
    });

    return quickSort(less, field).concat(equal, quickSort(greater, field));
}

// як allocator() у методичці: повторний клік по тому ж стовпцю
// не сортує заново, а лише перевертає масив
function sortBy(field) {
    if (field === sortField) {
        baristas.reverse();
        sortAsc = !sortAsc;
    } else {
        baristas = quickSort(baristas, field);
        sortField = field;
        sortAsc = true;
    }
    updateHeaderArrows();
    renderTable();
}
```

### 2.7 Аналітика

Усі три звіти залишилися в HTML, а скрипт показує лише вибраний. Метод classList.toggle з другим аргументом додає клас hidden усім звітам, крім вибраного. Кількість рядків у рядку стану не записана вручну, а рахується через querySelectorAll('tbody tr'). Звіт перемикається і при зміні списку (подія change), і кнопкою «Сформувати».

**Лістинг 2.13 - Файл analytics.js**

```javascript
// analytics.js - перемикання аналітичних звітів без перезавантаження сторінки.

const reportSelect = document.getElementById('query-select');
const runButton = document.getElementById('btn-run-query');
const statusLine = document.getElementById('report-status');
const reports = document.querySelectorAll('.report');

function showReport() {
    const selected = 'section-' + reportSelect.value; // наприклад, section-rank
    let rowsCount = 0;

    reports.forEach(function (section) {
        const isSelected = section.id === selected;
        // toggle з другим аргументом: true - додати клас, false - прибрати

        if (isSelected) {

    statusLine.textContent = 'Сформовано звіт «' + title + '». Рядків: ' + rowsCount + '. Час: ' + time + '.';
}

reportSelect.addEventListener('change', showReport);
runButton.addEventListener('click', showReport);
```

## ВИСНОВКИ

У лабораторній роботі сайт «Coffee Shop» отримав клієнтську логіку на JavaScript без сторонніх бібліотек. Дані чека, історії продажів, клієнтів, карток і персоналу зберігаються в масивах об'єктів, а таблиці будуються з них через DOM. Сторінку персоналу зроблено за прикладом з методички: конструктор записів, швидке сортування за кліком на заголовку і зворотний порядок при повторному кліку, при цьому порівняння рядків виконує localeCompare з українською локаллю.

На практиці застосовано обробку подій click, input, change, submit і reset, делегування подій, керування класами через classList, перевірку форм регулярними виразами та нарахування бонусів за правилами курсового застосунку. Увесь текст від користувача виводиться через textContent, тому введений HTML-код не виконується.
