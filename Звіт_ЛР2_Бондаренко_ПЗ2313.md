## 2 ХІД ВИКОНАННЯ РОБОТИ

### 2.1 Підключення стилів

Усі стилі зібрано в одному файлі style.css, який підключено в <head> кожної з п'яти сторінок тегом <link rel="stylesheet">. Зовнішній файл обрано тому, що зміна в ньому одразу діє на весь сайт, а браузер завантажує його один раз і далі бере з кешу. Атрибутів style та блоків <style> у сторінках немає. Також додано мета-тег viewport, без якого телефон показує сторінку зменшеною копією настільної версії і медіазапити не працюють.

**Лістинг 2.1 - Заголовна частина сторінки index.html**

```html
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Coffee Shop - Головна</title>
    <link rel="stylesheet" href="style.css">
</head>
```

### 2.2 Перенесення оформлення з HTML у CSS

Спочатку з розмітки ЛР1 прибрано все, що відповідало за вигляд: атрибути align, bgcolor, border, cellpadding, cellspacing, width, type у списків і теги <font>, <big>. Замість них елементам дано класи, а оформлення описано в style.css (таблиця 2.1). Теги <b>, <i>, <u>, <s>, <small>, <sup>, <sub> залишено, бо вони передають зміст тексту (наголос, стара ціна, індекс у формулі). Атрибути width і height залишено тільки в зображення карти: координати областей <area> задаються в пікселях, тому розмір картинки має бути фіксованим.

**Таблиця 2.1 - Заміна атрибутів оформлення на класи CSS**

### 2.3 Блочна верстка головної сторінки

Головну сторінку зібрано з блоків так само, як у прикладі з методички. Загальний контейнер .container має максимальну ширину 1100 px і вирівнюється по центру за рахунок margin: 0 auto. Усередині нього розміщено шапку, меню, блок .layout з двома колонками і підвал. Ліва колонка main.content займає 66% ширини і має float: left, права aside.sidebar займає 31% і має float: right. Щоб підвал не заходив під колонки, у блоку .layout задано overflow: hidden: так само в методичці працює клас .bottom_div.

**Лістинг 2.4 - Каркас головної сторінки (вміст блоків пропущено)**

```html
<div class="container">
    <header class="site-header"> ... </header>
    <nav class="main-nav"> ... </nav>

    <!-- дві колонки: основний вміст (float: left) і новини (float: right) -->
    <div class="layout">
        <main class="content"> ... </main>
        <aside class="sidebar"> ... </aside>
    </div>

    <footer class="site-footer"> ... </footer>
</div>
```

**Лістинг 2.5 - Стилі двох колонок (style.css)**

```css
/* головна сторінка: дві колонки на float.
   overflow: hidden скидає обтікання, як .bottom_div у методичці */
.layout {
    overflow: hidden;
}

.content {
    float: left;
    width: 66%;
}

.sidebar {
    float: right;
    width: 31%;
    margin-top: 28px;
}
```

Бічна колонка містить стрічку новин. Кожна новина побудована за схемою з методички, тільки замість окремих div для заголовка і тексту використано семантичні теги <h4> і <p>, а саму новину обгорнуто в <article>, як радить лекція 2. Відповідність класів наведено в таблиці 2.2.

### 2.4 Flexbox і Grid

Обтікання float зручне для двох колонок, але для дрібніших елементів використано сучасні способи розкладки з лекції 2. Flexbox (одновимірна модель) розкладає в рядок логотип і назву в шапці, пункти меню, підпис і поле в рядках форм, елементи панелі пошуку, суму і кнопки в підсумку чека та колонки підвалу. Grid (двовимірна модель) використано для трьох карток «Пропозиції тижня» (grid-template-columns: repeat(3, 1fr)) і для чотирьох списків розділу меню, розкладених у дві колонки.

**Лістинг 2.8 - Flexbox для шапки та меню, Grid для карток і списків (style.css)**

```css
/* шапка: логотип і назва в один рядок (flexbox) */
.site-header {
    display: flex;
    align-items: center;
    gap: 20px;
    padding-bottom: 16px;
    border-bottom: 1px solid var(--line);
}

.main-nav ul {
    display: flex;
    flex-wrap: wrap;
    margin: 0;
    padding: 6px;
    list-style: none;
}

/* ---------- 5. Картки пропозицій (CSS Grid) ---------- */
.offers {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 14px;
}

/* два списки поруч */
.two-columns {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 0 28px;
}
```

### 2.5 Блокова модель

Кожен елемент браузер розглядає як прямокутник з чотирьох шарів: вміст (content), внутрішній відступ (padding), рамка (border) і зовнішній відступ (margin). Для всіх елементів задано box-sizing: border-box, тому значення width включає padding і border. Наприклад, блок новини .news-item має padding: 14px 16px, рамку 1 px і margin-bottom: 12px. Внутрішня ширина контейнера дорівнює 1100 - 2 * 32 - 2 * 1 = 1034 px, бічна колонка займає 31% від неї, тобто приблизно 320 px. Оскільки padding і рамка входять у цю ширину, на текст новини залишається 320 - 2 * 16 - 2 * 1 = 286 px, і колонка не виходить за межі макета.

**Лістинг 2.9 - Модель border-box (style.css)**

```css
/* ширина блоку враховує padding і border */
* {
    box-sizing: border-box;
}
```

### 2.6 Селектори, каскад і специфічність

У файлі стилів використано різні види селекторів (таблиця 2.3).

**Таблиця 2.3 - Види селекторів у style.css**

| Вид селектора | Приклад | Призначення |
| --- | --- | --- |
| тег | body, h2, fieldset | базовий шрифт, фон, заголовки |
| клас | .container, .btn, .news-item | більшість правил проєкту |
| ідентифікатор | #lbl-total | велика сума до сплати в чеку |
| нащадок | .main-nav a, .offer-card h3 | посилання меню, заголовок картки |
| дочірній елемент | .form-row > label:first-child | підпис поля фіксованої ширини |
| сусідній елемент | .data-table thead tr + tr th | другий рядок дворівневої шапки |
| атрибут | input[type="text"], th[colspan] | поля форм, заголовок над кількома стовпцями |
| псевдоклас | :hover, :focus, :nth-child(even), :root | наведення, фокус, «зебра», змінні |
| псевдоелемент | blockquote::before | велика лапка перед цитатою |
| групування | h1, h2, h3, h4, h5, h6 | спільний колір заголовків |

Під час оформлення таблиць звітів виникла ситуація, яка добре показує роботу каскаду. Правило «зебри» .data-table tbody tr:nth-child(even) має специфічність (0,2,2): клас, псевдоклас і два теги. Селектор .data-table tbody tr.subtotal для підсумкового рядка має таку саму вагу, а при однаковій вазі перемагає правило, записане у файлі пізніше. Через це підсумковий рядок на парній позиції міг отримати колір зебри замість жовтого. Щоб результат не залежав від порядку правил, у селектор додано тег table: table.data-table tbody tr.subtotal має специфічність (0,2,3) і перемагає і «зебру», і :hover. Схожа ситуація була з вирівнюванням заголовків: правило .data-table th (0,1,1) сильніше за .center (0,1,0), тому для таблиць додано правила .data-table .center і .data-table .num з вагою (0,2,0).

**Лістинг 2.10 - Правила таблиць (style.css)**

```css
/* "зебра" та підсвічування рядка під курсором */
.data-table tbody tr:nth-child(even) {
    background-color: #faf8f5;
}

.data-table tbody tr:hover {
    background-color: #f2eee7;
}

/* підсумкові рядки звітів. Селектор table.data-table має специфічність (0,2,3),
   тому перемагає "зебру" та :hover зі специфічністю (0,2,2) */
table.data-table tbody tr.subtotal {
    background-color: #fff3cd;
    font-weight: 600;
}

table.data-table tbody tr.cube-total {
    background-color: #d1ecf1;
}

table.data-table tbody tr.grand-total {
    background-color: #d4edda;
    font-weight: 700;
}

.center {
    text-align: center;
}

.num {
    text-align: right;
    white-space: nowrap;
}

/* для заголовків таблиці потрібна більша специфічність,
   ніж у .data-table th (0,1,1), інакше вирівнювання не спрацює */
.data-table .center {
    text-align: center;
}

.data-table .num {
    text-align: right;
}

/* не переносити телефони та години роботи */
.nowrap {
    white-space: nowrap;
}
```

### 2.7 Змінні CSS і псевдоелементи

Кольори фірмової палітри винесено у змінні в правилі :root, а в інших правилах вони підставляються через var(). Якщо потрібно змінити, наприклад, основний коричневий колір, достатньо виправити одне значення. Перед цитатою псевдоелемент ::before малює велику лапку, тому в HTML для неї не потрібен окремий тег.

**Лістинг 2.11 - Змінні та псевдоелемент (style.css)**

```css
:root {
    --coffee-dark: #3d251c;
    --coffee: #533529;
    --coffee-medium: #734c3d;
    --caramel: #8b5a2b;
    --cream: #f7f4ee;
    --cream-light: #faf6f0;
    --line: #e2ded4;
    --text: #333333;
    --text-light: #776b5d;
    --green: #2e7d32;
    --red: #c93b2b;
    --radius: 6px;
}

/* велика лапка перед цитатою (псевдоелемент) */
blockquote::before {
    content: "\201C";
    position: absolute;
    left: 12px;
    top: -6px;
    color: var(--caramel);
    font-family: Georgia, serif;
    font-size: 48px;
}
```

### 2.9 Адаптивність

Для вузьких екранів додано два медіазапити. При ширині до 900 px колонки скасовують обтікання і стають одна під одною, картки й списки вишиковуються в одну колонку. При ширині до 600 px шапка і меню перебудовуються вертикально, а поля форм розтягуються на всю ширину. Зображення карти не масштабується, бо інакше координати областей перестануть збігатися з малюнком, тому для нього задано горизонтальну прокрутку overflow-x: auto.

**Лістинг 2.13 - Медіазапити (style.css)**

```css
/* ---------- 14. Адаптивність ---------- */

/* планшет: колонки одна під одною */
@media (max-width: 900px) {
    .content,
    .sidebar {
        float: none;
        width: auto;
    }

    .offers,
    .two-columns {
        grid-template-columns: 1fr;
    }
}

/* телефон */
@media (max-width: 600px) {
    body {
        padding: 0;
    }

    .container {
        padding: 16px;
        border-radius: 0;
    }

    .site-header {
        flex-direction: column;
        text-align: center;
    }

    .main-nav ul {
        flex-direction: column;
    }

    .form-row > label:first-child {
        width: 100%;
    }

    input[type="text"],
    input[type="tel"],
    input[type="email"],
    select {
        width: 100%;
        min-width: 0;
    }

    .data-table {
        font-size: 12px;
    }
}
```

## ВИСНОВКИ

У лабораторній роботі сайт «Coffee Shop» оформлено за допомогою одного зовнішнього файлу style.css. З HTML прибрано атрибути оформлення та теги <font> і <big>, замість них використано класи. Головну сторінку зібрано з блоків: дві колонки на float зі скиданням обтікання через overflow, стрічка новин за схемою з методички. Для дрібніших елементів застосовано Flexbox і Grid, кольори винесено у змінні CSS.

На практиці розібрано блокову модель і box-sizing, каскад і специфічність селекторів (зокрема, чому правило «зебри» перекривало колір підсумкових рядків), псевдокласи і псевдоелементи, а також медіазапити для телефонів.
