# Лекція 2. Сучасні стандарти верстки: HTML5 та CSS3

## 1. Еволюція стандарту HTML5

HTML5 — це сучасна ревізія стандарту мови розмітки веб-документів, прийнята W3C та WHATWG. Її головна мета полягала в оптимізації мови для підтримки мультимедійних додатків, покращенні доступності (accessibility) та впровадженні однозначної семантичної структури документа.

### Ключові нововведення HTML5:
1. **Спрощений синтаксис DOCTYPE:**
   Замість складних SGML-оголошень DTD тепер використовується мінімалістичний запис:
   ```html
   <!DOCTYPE html>
   ```
2. **Нативна підтримка аудіо та відео:**
   Повна відмова від сторонніх плагінів (Adobe Flash, Microsoft Silverlight) на користь стандартизованих тегів `<audio>` та `<video>`:
   ```html
   <video controls width="640">
       <source src="intro.mp4" type="video/mp4">
       Ваш браузер не підтримує тег відео.
   </video>
   ```
3. **Елемент `<canvas>` та підтримка вбудованого SVG:**
   Дозволяють малювати 2D/3D графіку на льоту за допомогою JavaScript та вбудовувати векторну графіку без втрати якості.
4. **Нові типи полів введення форми (`<input>`):**
   - `type="email"` — автоматична перевірка коректності e-mail адреси.
   - `type="tel"` — оптимізована цифрова клавіатура на смартфонах.
   - `type="number"` — числовий ввід з атрибутами `min`, `max`, `step`.
   - `type="date"` — нативний календар для вибору дати.
   - `type="range"` — повзунок вибору числового діапазону.
   - Атрибути валідації: `required`, `pattern`, `placeholder`, `autofocus`.

## 2. Семантичні елементи HTML5

**Семантика у вебі** — це використання HTML-тегів відповідно до їхнього змістовного та структурного призначення, а не за їхнім візуальним виглядом.

### Головні семантичні блоки HTML5:
- `<header>`: «Шапка» сторінки або окремого логічного розділу. Зазвичай містить логотип, слоган, назву сайту або блок пошуку.
- `<nav>`: Контейнер для основних навігаційних посилань (головне меню сайту, хлібні крихти, пагінація).
- `<main>`: Головний унікальний контент сторінки. На одній сторінці має бути присутній лише один тег `<main>`.
- `<section>`: Тематичний розділ документа (наприклад, розділ «Про нас», секція «Каталог напоїв», відгуки). Зазвичай має власний заголовок `<h2>`–`<h6>`.
- `<article>`: Завершений, самостійний блок контенту, який можна вилучити зі сторінки та розповсюджувати окремо (новина, пост у блозі, картка товару, коментар).
- `<aside>`: Додаткова інформація, не пов'язана напряму з основним контентом (бічна панель / сайдбар, швидкі посилання, віджет погоди, блок акцій).
- `<footer>`: «Підвал» сторінки. Містить копірайти, контакти, юридичну інформацію, посилання на соцмережі.
- `<figure>` та `<figcaption>`: Контейнер для ілюстрацій, фотографій, схем та їхнього текстового підпису.

### Переваги семантичної верстки:
1. **Пошукова оптимізація (SEO):** Роботи Google та Bing краще індексують сторінку та розуміють ієрархію інформації.
2. **Доступність (Accessibility / A11y):** Програми читання з екрана (Screen Readers) для людей з порушеннями зору забезпечують зручну навігацію за орієнтирами (landmarks).
3. **Чистота та читабельність коду:** Відмова від «div-soup» (нескінченних вкладених тегів `<div>`).

## 3. Стандарт CSS3 та сучасні можливості стилізації

CSS3 розбив монолітну специфікацію на незалежні модулі, кожен з яких розвивається окремо.

### 3.1. Візуальні ефекти та декоративні властивості
- `border-radius`: Округлення кутів блоків і кнопок (створення круглих аватарів через `50%`).
- `box-shadow` та `text-shadow`: Створення м'яких тіней для надання глибини інтерфейсу (матеріальний дизайн / карткова верстка).
- `background: linear-gradient(...)`: Плавні кольорові градієнти без потреби у важких растрових зображеннях.
- `opacity` та `rgba()`: Керування прозорістю фону або елемента.

### 3.2. Сучасні системи розмітки (Layout Engines)
1. **Flexbox (Flexible Box Layout):**
   - Одновимірна модель розмітки (горизонтальна або вертикальна вісь).
   - Властивості контейнера: `display: flex`, `flex-direction`, `justify-content`, `align-items`, `gap`.
   - Ідеально підходить для навігаційних панелей, списків кнопок, вирівнювання іконок з текстом.
2. **CSS Grid Layout:**
   - Двовимірна модель розмітки (одночасна робота з рядками та стовпчиками сітки).
   - Властивості: `display: grid`, `grid-template-columns: repeat(3, 1fr)`, `grid-gap`.
   - Ідеально підходить для глобального каркаса сторінки, каталогів товарів, аналітичних дашбордів.

### 3.3. Адаптивний дизайн та Медіа-запити (Media Queries)
Адаптивність забезпечує коректне та зручне відображення сайту на дисплеях будь-якого розміру: смартфонах, планшетах, ноутбуках і широкоформатних моніторах.

Синтаксис медіа-запиту:
```css
/* Базові стилі для ПК */
.container {
    width: 1100px;
    margin: 0 auto;
}

/* Правила для мобільних екранів (до 768px) */
@media (max-width: 768px) {
    .container {
        width: 100%;
        padding: 0 15px;
    }
    .nav-menu {
        flex-direction: column;
    }
}
```

## 4. Висновок
Сучасний стек HTML5 та CSS3 надає веброзробникам повний інструментарій для створення чистих, семантично виразних, візуально привабливих та адаптивних інтерфейсів без використання застарілих табличних чи виключно float-орієнтованих каркасів.
